Votación Pedagógica

Simula el registro de un voto ficticio para practicar cómo una aplicación web envía datos al servidor y los guarda en un archivo JSON.

Registrar voto

Esta sección es el formulario de votación. Aquí escribes una identificación inventada (no uses cédula ni datos reales) y eliges un perfil de la lista. Al pulsar el botón, el navegador envía un POST a /api/votos y el servidor guarda el voto en votos carpeta/votos.json. Cada identificación ficticia solo puede votar una vez.

Candidatos disponibles

Esta lista se carga automáticamente desde el servidor con GET /api/candidatos. Muestra los mismos perfiles ficticios que ves en la página principal, para que puedas leer rol y propuesta antes de elegir en el formulario de arriba.

Consultar votos registrados

Este bloque sirve para comprobar que los votos quedaron guardados. Al pulsar el botón, la página pide los datos con GET /api/votos y los muestra en tarjetas. Así puedes verificar en clase que el archivo JSON del servidor recibe y devuelve información correctamente.
